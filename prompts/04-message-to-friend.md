I packaged my internship-search workflow into a setup kit you can use in your own account:

https://github.com/SachinVedGupta/internship-search-starter-kit

Make a ChatGPT project called “Internship Search” and tell your agent: “Read and follow SETUP.md in this repository to interview me and set up my internship-search system, using the included dashboard code.” The README has a one-line prompt with the exact file link. If your agent cannot fetch the files, upload CHATGPT-SETUP-PACK.md and the repository ZIP when requested. Add your resume when it asks. It starts by interviewing you, then helps set up your own profile, job tracker, dashboard, resumes and application drafts. Working dashboard code is included, so it can launch/adapt that rather than build everything from scratch. You'll connect your own Google account and other tools as needed. You still review and submit applications yourself.

Desktop Work/Codex is useful for the fuller setup if your account supports it; the prompt checks available tools and can start with documents and drafts. My personal information and applications aren't included.
