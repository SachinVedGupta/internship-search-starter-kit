I packaged my internship-search workflow into a setup kit you can use in your own account:

https://github.com/SachinVedGupta/internship-search-starter-kit

Download CHATGPT-SETUP-PACK.md, make a ChatGPT project called “Internship Search,” upload the file and paste the prompt linked in the README. Add your resume when it asks. It starts by interviewing you, then helps set up your own profile, job tracker, dashboard, resumes and application drafts. Working dashboard code is included, so it can launch/adapt that rather than build everything from scratch. You'll connect your own Google account and other tools as needed. You still review and submit applications yourself.

Desktop Work/Codex is useful for the fuller setup if your account supports it; the prompt checks available tools and can start with documents and drafts. My personal information and applications aren't included.
