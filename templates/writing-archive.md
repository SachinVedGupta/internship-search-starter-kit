# Career Writing Archive

Private. Preserve approved versions and user writing.

For each answer, cover letter or story:
- Stable ID, type and related career/application record
- Exact prompt/audience and character limit
- Current draft text and user-edited version
- Supporting facts/source references, separate from polished prose
- Assumptions, missing facts and confidentiality constraints
- Review status: Draft / Needs review / User-approved
- Content version and what the user approved
- Historical versions, dates and usage
- Hub record link and per-destination readback status

Never interpret storage as approval, or a previous draft as proof of the underlying facts.
