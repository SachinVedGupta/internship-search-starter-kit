## To Apply

For each record: stable ID; employer; exact title/requisition; official URL; term/location; priority and rationale; availability; stage; Posted (unknown if absent); earliest Found On; last Verified; eligibility and gaps; questions/drafts link; selected resume/version; blockers; next action and due date; manual notes; revision/history.

Drafts and partially filled applications stay Need Action. Do not create a false Applied record as a test.

## Applied

For each record: same stable identity; actual submission date and labelled evidence; current stage/outcome; OA/interview deadlines; resume used; confirmation link; next action; manual notes and history.

## Sync history

Run ID; changed record/fields; dashboard result; tracker result; changed-field readbacks; unresolved conflicts/pending actions. A write response alone is not verified sync.
